A beautiful, interactive family tree web application for the Keelapavoor family. 
View, search, add, edit, and manage family members across 5 generations.

## ✨ Features

- 🌳 **Interactive Family Tree** — 5 generations with visual connections
- 🔍 **Smart Search** — Find members by name, role, or bio
- ➕ **Add/Edit Members** — Easily update family information
- 🎂 **Birthday Calendar** — Monthly view with today's highlights
- 💍 **Anniversary Tracker** — Never miss a wedding anniversary
- 📷 **Photo Gallery** — Family photos organized by generation
- 📱 **Mobile Responsive** — Works perfectly on phones and tablets
- 💾 **Offline Support** — All data stored locally in the browser
